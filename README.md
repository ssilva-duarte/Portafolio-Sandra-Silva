Soy **odontóloga y especialista en Epidemiología**, con **más de 15 años de experiencia** en vigilancia en salud pública en Colombia. ### ✏️ Cómo personalizarlo

Abre `index.html` y busca el bloque `CONFIGURA AQUÍ TUS ENLACES`, al inicio del `<script>`:

```js
const CONTACTO = {
  email: "tu-correo-profesional@ejemplo.com", // vacío = no se muestra el botón "Escríbeme"
  linkedin: ""                                // opcional: si lo llenas, aparece el botón de LinkedIn
};
```

### 🚀 Publicarlo con GitHub Pages

1. Sube `index.html` y `README.md` a un repositorio.
2. Ve a **Settings → Pages**.
3. En *Source* elige la rama `main` y la carpeta `/ (root)`.
4. Guarda. En uno o dos minutos tu portafolio estará en línea.
